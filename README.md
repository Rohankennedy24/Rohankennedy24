## 🛡️ 01 — AI-Powered Insider Threat Detection

<p align="center">
  <img src="https://img.shields.io/badge/AI-Cybersecurity-red?style=for-the-badge"/>
  <img src="https://img.shields.io/badge/ML-Isolation%20Forest-blue?style=for-the-badge"/>
  <img src="https://img.shields.io/badge/XAI-SHAP-purple?style=for-the-badge"/>
  <img src="https://img.shields.io/badge/Language-Python-yellow?style=for-the-badge&logo=python"/>
</p>

An AI-driven cybersecurity system designed to identify **abnormal and potentially malicious user behaviour** from activity logs.

The system applies the **Isolation Forest** anomaly detection algorithm to identify subtle and previously unseen behavioural patterns. It also integrates **SHAP-based Explainable AI** to provide insights into why an activity was considered anomalous.

### 🔍 Key Concepts

- User Behaviour Monitoring
- Anomaly Detection
- Isolation Forest
- Explainable AI
- SHAP
- Cybersecurity Analytics
- Behavioural Analysis

An ongoing research-oriented project focused on improving the **reliability and trustworthiness of Multi-Agent AI systems**.

The system aims to identify the agent responsible for an incorrect or hallucinated response, repair the problematic agent, and resume the workflow without unnecessarily restarting the complete execution.
